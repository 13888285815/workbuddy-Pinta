# Pinta Web - 在线绘图工具

🎨 **Pinta Web** 是一个基于 HTML5 Canvas 的在线图像编辑工具，灵感来源于 Pinta 桌面应用程序。

## 功能特性

### 🖌️ 绘图工具
- **铅笔** - 基本绘图工具
- **画笔** - 支持硬度和透明度调整
- **橡皮擦** - 擦除工具
- **油漆桶** - 洪水填充工具
- **文字** - 添加文字到图像

### 📐 形状工具
- **矩形** - 绘制矩形
- **椭圆** - 绘制椭圆
- **直线** - 绘制直线
- **箭头** - 绘制箭头

### 🎯 选择和移动
- **矩形选择** - 选择矩形区域
- **椭圆选择** - 选择椭圆区域
- **套索** - 自由选择
- **移动** - 移动图层内容

### 🎨 颜色工具
- **取色器** - 从图像中选取颜色
- **颜色面板** - 快速选择颜色
- **自定义颜色** - 使用颜色选择器

### 📚 图层管理
- 添加/删除图层
- 调整图层顺序
- 设置图层不透明度
- 选择混合模式
- 复制图层
- 向下合并图层

### ✨ 图像效果
- **模糊** - 高斯模糊
- **锐化** - 锐化效果
- **浮雕** - 浮雕效果
- **灰度** - 转换为灰度
- **反色** - 颜色反转
- **复古** - 怀旧色调
- **亮度/对比度** - 调整亮度和对比度

### 📁 文件操作
- 新建文档
- 打开图片
- 保存为 PNG
- 导出为 JPG

### 🔍 视图控制
- 放大/缩小
- 平移画布
- 显示/隐藏网格

## 快速开始

### 方法 1: 直接打开
双击 `index.html` 文件，在浏览器中打开。

### 方法 2: 使用本地服务器（推荐）

**macOS/Linux:**
```bash
./start-server.sh
```

**Windows:**
```cmd
start-server.bat
```

或者手动启动：
```bash
python3 server.py
```

然后在浏览器中打开 `http://localhost:8000`

## 快捷键

### 文件操作
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建文档 |
| `Ctrl+O` | 打开图片 |
| `Ctrl+S` | 保存图片 |

### 编辑操作
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |

### 工具
| 快捷键 | 工具 |
|--------|------|
| `P` | 铅笔 |
| `B` | 画笔 |
| `E` | 橡皮擦 |
| `G` | 油漆桶 |
| `T` | 文字 |
| `R` | 矩形 |
| `O` | 椭圆 |
| `L` | 直线 |
| `S` | 矩形选择 |
| `M` | 移动 |
| `I` | 取色器 |

### 颜色
| 快捷键 | 功能 |

## 技术栈

- **HTML5 Canvas** - 绘图引擎
- **Vanilla JavaScript** - 无框架依赖
- **CSS3** - 现代化UI设计
- **Python** - 本地服务器（可选）

## 浏览器支持

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

## 项目结构

```
web-version/
├── index.html          # 主页面
├── css/
│   └── style.css      # 样式表
├── js/
│   ├── utils.js       # 工具函数
│   ├── history.js     # 历史记录管理
│   ├── layers.js      # 图层管理
│   ├── tools.js       # 绘图工具
│   ├── effects.js     # 图像效果
│   └── app.js         # 主应用程序
├── server.py          # Python HTTP 服务器
├── start-server.sh    # 服务器启动脚本 (macOS/Linux)
├── start-server.bat   # 服务器启动脚本 (Windows)
└── README.md          # 本文件
```
